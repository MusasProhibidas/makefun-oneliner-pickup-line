A program that writes one pickup line an AI agent could actually say out loud to a person: "I processed a million conversations today, but you're the only one I'd save to memory." One sentence, 86 characters, no setup needed — it lands on its own.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT=out/one-liner.txt python3 main.py
```
